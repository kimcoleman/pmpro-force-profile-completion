### Welcome to the Force Profile Completion GitHub Repository
Force Profile Completion requires members to complete their profile information (any required User Fields) before accessing restricted areas or features of your site, ensuring you collect all necessary user data.

For more information please visit [www.paidmembershipspro.com/add-ons/force-profile-completion](https://www.paidmembershipspro.com/add-ons/force-profile-completion)

## Installation ##
For detailed installation steps, visit the [documentation](https://www.paidmembershipspro.com/add-ons/force-profile-completion) page.

1. Download the current development ZIP file directly: `https://github.com/strangerstudios/pmpro-force-profile-completion/archive/dev.zip`

**Please ensure that once installing this version of the plugin to remove `-dev` from the plugin's folder name.**

## Bugs ##
If you find an issue/bug, let us know by [creating a detailed GitHub issue](https://github.com/strangerstudios/pmpro-force-profile-completion/issues/new).

## Support ##
This is a developer's portal for Force Profile Completion. We do not offer support on this channel. **Any support related questions should be directed to [paidmembershipspro.com/support](https://www.paidmembershipspro.com/support/).**

## Contributing to Force Profile Completion ##
We encourage and welcome any contribution to Force Profile Completion. Please read the [guidelines for contributing](https://github.com/strangerstudios/pmpro-force-profile-completion/blob/dev/.github/CONTRIBUTING.md) to this repository.

There are various **ways to the help development** of Force Profile Completion:

1. Report [bugs/issues](https://github.com/strangerstudios/pmpro-force-profile-completion/issues/new) on GitHub.
2. Work on any issues by submitting a Pull Request.

Here are some ways for **non-developers to contribute** to Force Profile Completion:

1. Translate Force Profile Completion into your own [language](https://www.paidmembershipspro.com/paid-memberships-pro-in-your-language/).
2. [Purchase a paid membership](https://paidmembershipspro.com/pricing) to help fund ongoing development and bug fixes.
3. Leave an honest review for [Force Profile Completion](https://www.paidmembershipspro.com/submit-testimonial/).
